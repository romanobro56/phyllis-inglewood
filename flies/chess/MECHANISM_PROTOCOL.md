# Corrected rewards and learning mechanism protocol

This local follow-up uses the actual tiny FlyWire graph only. It is an engineering study, not an external preregistration. All previous test data is retired for model selection. No shared GPU action is authorized.

## Ordered experiments

1. Validate integer-v2 against an independent rational reward oracle, including own-turn opponent replies, on existing **validation** trajectories. Disable entropy and use lr=0 for diagnostic backward passes. Then repeat the original 56-update intact training at seeds 11/23/37 with integer-v2 and exactly the prior starts, budget and hyperparameters. Compare fixed weights, optimizer states and validation performance with the archived float-v1 runs. This tests a numerical correction, not a new curriculum.
2. Use training/validation data only for a small mechanism pilot. Compare prior-update EMA and leave-one-out (LOO) baselines on **identical grouped starts and budgets**. Independent rollouts of the same FEN, color, players and frozen-per-update weights supply LOO scores; never use a rollout's own reward or a different counterfactual board as its baseline. No added neural critic/readout, label loss, answer-valued policy input or engine action is allowed.
3. Use a curriculum that rehearses exact-legal-tree matched mate-one pairs, then mixes sampled mate-two roots with curated mate-one suffix starts derived from **training roots only**. Suffix starts are rule-curated positions, not prefix moves chosen for either fly in a played game. Disclose their curation and treat success as task-specific. Neither root proof labels nor auxiliary engine scores enter the training objective; only sampled actual terminal outcomes do. Both strategic players are independent live FlyBrains.
4. After the pilot, freeze a new evaluation manifest before generating/opening fresh test positions or running main model comparisons. Record fixed budgets, checkpoints, seed/learner choice, metrics, uncertainty, family exclusions and scaling gates. Then run intact EMA, intact LOO and an independently trained stage-only restriction with the same budgets. The pilot chooses no best checkpoint, learner or test position. If validation is negative, retain that finding; do not keep tuning against a test set.

## Initial candidate specification (before pilot)

Two live independent brains are warm-started from the corrected 56-update replication. Pilot starts from seed-11 replication weights with action-sampling seed 101. Candidates differ only in baseline: EMA versus LOO, common lr=.003, entropy=.0005, gamma=1, gradient chunk64, group size8, 16 updates ×128 games. An additional entropy-only control zeroes training rewards/baselines while still recording real outcomes; it is included before inspecting pilot validation results. First half samples the training quartile with highest **minimum** uniform-legal mate opportunity across each matched pair; second half samples all training pairs. This stratum is created once by dataset curation, not recomputed by policy outputs. It improves opportunity density without supplying answers to a policy. Matched games cap at two plies and failed mates remain unfinished or actual rule draws.

Main candidate budget is 48 updates ×128 games: first 32 matched, last 16 with 64 matched /32 curated suffix /32 mate-two games per update. Caps are 2/2/4 plies. Equal games and ply caps are matched; realized neural decision counts and elapsed time are reported because early terminations differ. Every group has eight independent action RNG streams; group context and rewards are frozen before either optimizer step. Compare exact matched-board adaptation on existing validation families at fixed checkpoints, not sampled training reward alone. Suffixes have separate provenance and split integrity checks.

All observation restrictions are deliberate scientific controls through the same FlyBrain and fixed legal coordinate interface. Parent/untrained policies are frozen independent checkpoints; random-legal and actual-lesion policies are evaluation controls only. Full chess outcomes and playing strength are outside this short-horizon learning-mechanism study.
